# Station directory

`public/rail/stations.csv` is an unmodified copy of the CSV from
[davwheat/uk-railway-stations](https://github.com/davwheat/uk-railway-stations),
commit `67dff87f51bdb782ddfcce1d8b10a88f059bf380`. Its publisher attributes
Trainline EU and the sources of [Trainline's station data](https://github.com/trainline-eu/stations#licence):
OpenStreetMap, SNCF OpenData, GeoNames, Digitraffic.fi, OpenTransportData.swiss,
and admin.ch. The CSV is made available under the Open Database License 1.0;
see [ODbL.txt](./ODbL.txt). The publisher says it contains stations queryable
through National Rail Darwin. It is not a directory of Northern Ireland rail.

Attribution must accompany public use. The CSV is included unchanged and is
loaded only when the station field is used. This source and its licence should
be reviewed again when the directory is updated.
